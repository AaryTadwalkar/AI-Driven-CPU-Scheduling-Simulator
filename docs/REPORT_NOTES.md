## 2. Detailed Empirical Findings (Stage 7 Test Split)

### 2.1 Context Switch Cost = 0 (Ideal Free Preemption)
- **Preemptive Waiting Time Optimum:** `SRTF` achieves the theoretical minimum mean waiting time of **14.41 ± 1.30 ticks** and turnaround of **22.30 ± 1.62 ticks**.
- **Reinforcement Learning Convergence:** Tabular `RL` closely approaches SRTF with **16.74 ± 1.40 ticks** mean waiting time. Crucially, RL achieves an Average Response Time of **9.59 ± 0.78 ticks**, beating non-preemptive SJF (17.57 ticks) and FCFS (21.27 ticks) by nearly 2x.
- **Fairness & Starvation:** While SRTF exhibits a high **35.8%** starvation incidence (processes waiting > 3x the mean), RL achieves **15.7%** starvation with a Jain fairness index of **0.854 ± 0.004**.
- **Interactive Response:** `Round Robin (q=2)` delivers the lowest response time (**3.96 ± 0.17 ticks**) and highest fairness (**0.913 ± 0.005**), but suffers from high waiting (**27.92 ± 2.61 ticks**) and 27.0 context switches.

### 2.2 Context Switch Cost = 1 (Realistic Overhead)
- **The Preemption Penalty:** When CPU context switches cost 1 integer tick, Round Robin performance degrades dramatically to **47.88 ± 4.13 ticks** waiting time (a 71% increase) due to paying 27.2 ticks in overhead.
- **Learned RL Adaptation:** Under `cs_cost = 1`, the Q-learning agent trained with switching penalties learns to favor `CONTINUE_CURRENT` in intermediate states. Its average context switches drop from **13.6 to 7.4**, achieving **19.14 ± 1.34 ticks** waiting time and a starvation rate of only **8.4%** (compared to 18.4% for SRTF and 13.2% for SJF).
- **Decision Tree Supervised Recommendation:** Across the 1,000 test workloads, the Decision Tree recommender achieves **90.20% accuracy** and a **macro-F1 score of 0.8878** against composite Pareto ground truth.
- **Regret Analysis:**
  - Decision Tree Regret: **0.0487**
  - Always-SJF Fixed Baseline Regret: **0.2655** (5.4x worse than DT)
  - Always-RR Fixed Baseline Regret: **0.4110** (8.4x worse than DT)
  - Always-FCFS Fixed Baseline Regret: **0.5402** (11.1x worse than DT)
  This quantitatively demonstrates that meta-policy selection per workload profile dramatically outperforms any static single algorithm.

## 4. Honest Technical Limitations & Discussion

In accordance with scientific integrity guidelines (Section 1.4 of Implementation Plan):

1. **Tabular State Space Discretization:**
   The RL agent uses a 7-tuple permutation-invariant aggregate state ($\le 3,200$ raw states). While achieving an unseen state rate of only $0.07\%$ on validation and generalising well across job counts, state aggregation necessarily pools workloads with slightly different ready queue shapes into identical buckets.
2. **SRTF Bound at Zero Overhead:**
   At `cs_cost = 0`, Shortest Remaining Time First (SRTF) is mathematically proven to minimize total waiting time for single-core scheduling. A reinforcement learning agent cannot surpass SRTF on waiting time alone when preemption is free. The true value of RL appears at `cs_cost > 0`, where the agent balances preemption benefits against switching penalties, halving context switches while avoiding starvation.
3. **Decision Tree Label Trade-offs:**
   Because the Decision Tree is trained on a composite objective ($0.5 \times \text{wait} + 0.3 \times \text{resp} + 0.2 \times \text{tat}$ at `cs_cost = 1`), it intentionally sacrifices pure waiting time minimisation when Round Robin offers vastly superior response times or FCFS avoids switching penalties.
4. **Synthetic Workloads vs. Hardware Reality:**
   The evaluation utilizes 9 parameterized synthetic scenarios. Real operating system workloads feature asynchronous hardware interrupts, I/O burst phases, and memory cache thrashing that discrete integer-tick models abstract away.
